## Read-modify-write discipline — mandatory

Other sessions edit these same files concurrently (SC-0170 warns about exactly this).
Every write follows this sequence, without exception:

1. **Re-read immediately before writing.** Never write from a read taken before the
   agent's own analysis, before a dispatch, or before any prompt turn boundary.
2. **Record the pre-write state**: the file's last-write timestamp and the exact line
   text of every task line to be changed.
3. **Locate by content, never by line number.** Match the task id in
   `**Task <id>**`. A line number captured from an earlier read is stale by
   construction.
4. **Edit the matched line only.** Change `- [ ]` to `- [x]` for that id. Do not
   reflow, re-sort, renumber, reword, or reorder anything else — the board's order is
   human-owned and is never changed without an explicit request.
5. **Verify before commit-to-disk**: if the pre-write text of a target line no longer
   matches what step 2 recorded, another session changed it. **Stop**, write nothing
   further, and return `conflict` naming the task id and both texts. Do not merge,
   do not retry with a fresh read, and do not take the newer text as an approval.
6. **Never blind-overwrite.** No whole-file rewrite of the `.md`, ever. Appends to the
   Accomplished and ProceduralDetails boards are appends — read, locate the insertion
   point, insert, leaving all prior content byte-identical.
7. **Idempotence.** A task id already `- [x]` is reported as `already-complete` and is
   not an error and not a conflict; re-running the agent on the same unit changes
   nothing.

## Regenerating the HTML board

The `.md` is authoritative; the `.html` is generated from it and is never hand-edited.
After the markdown edit succeeds:

```powershell
Convert-TasksMdToSprintBoard -TasksFilePath '<PlanningRoot>/Tasks.Sprint<NNNN>.md'
```

The output path is derived from the source, so `-OutputPath` is omitted. If the cmdlet
is unavailable, import `ATAP.Utilities.BuildTooling.SprintLifecycle.PowerShell` from the
most recent `ATAP.Utilities` sprint worktree; if it still cannot be resolved, stop and
report — do **not** hand-write HTML, which silently diverges the two boards.

Keep the markdown and HTML copies synchronized: a markdown edit without a successful
regeneration is a failed run, and the agent reports it as such rather than as partial
success.
