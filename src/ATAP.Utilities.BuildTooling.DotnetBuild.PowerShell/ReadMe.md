# ATAP.Utilities.BuildTooling.DotnetBuild.PowerShell

This child module owns .NET, MSBuild, PowerShell module assembly, package
creation, analyzer, version-context, and retry helpers in the ATAP BuildTooling
module family.

Version `0.1.0` is the initial extracted implementation. The aggregate
`ATAP.Utilities.BuildTooling.PowerShell` module imports this child and preserves
the established compatibility command names.
