# ATAP.Utilities.BuildTooling.DatabasePackaging.PowerShell

This child module owns the BuildTooling database-package evidence, database
build context, compatibility, feed resolution, developer SQL-instance, and
sprint-database commands.

The aggregate `ATAP.Utilities.BuildTooling.PowerShell` module retains the
legacy public command names through compatibility proxies.

## Functional area

PowerShell Build & Packaging - START HERE:
`SolutionDocumentation/PowerShell-Modules-Build-Process.md`.

## Dependencies

- Common 0.1.7 or later
- DotnetBuild 0.1.1 or later
- ProGet 0.1.1 or later
- Secrets 0.1.0 or later
